# 🏭 AI-Powered Asset Intelligence Platform

An Explainable AI platform for intelligent asset prioritization using:

- 📷 Computer Vision (YOLOv8)
- 🌡 Sensor Data
- 📋 Maintenance History
- 👨‍🔧 Engineer Notes
- 🌦 Weather Data

## Features

- Corrosion Detection
- RUL Prediction
- AI Decision Engine
- Live Dashboard
- Asset Priority Ranking
- Maintenance Recommendation

- Python
- Streamlit
- YOLOv8
- Scikit-learn
- Plotly
- Pandas
